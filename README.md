# Recoil Motor Controller Firmware for B-G431B-ESC1
This project is based on https://github.com/T-K-233/Recoil-Motor-Controller-BESC repository of [Berkeley Humanoid Lite](https://berkeley-humanoid-lite.gitbook.io/docs) that uses similar motors, but different sensor ([AS5600](https://www.alldatasheet.com/datasheet-pdf/view/621657/AMSCO/AS5600.html) Magnetic Encoder), while we use [AEDT-9810-ZOO](https://docs.broadcom.com/doc/AEDT-981x-Three-Channels-Optical-Incremental-Encoder-Modules-DS) Encoder.

## Useful info
1. **IDE:** You need to install STM32CubeIDE. Click [here](https://www.st.com/en/development-tools/stm32cubeide.html) for install.
2. **Hardware:** This firmware targets the [B-G431B-ESC1 Discovery Kit](https://www.st.com/en/evaluation-tools/b-g431b-esc1.html).
3. **Documentation:** Here is the official [User Manual for B-G431B-ESC1 (UM2516)](https://www.st.com/resource/en/user_manual/um2516-electronic-speed-controller-discovery-kit-for-drones-with-stm32g431cb-stmicroelectronics.pdf).
